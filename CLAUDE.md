# country-fare-finder

Web app that answers "I know the country, not the cities": it prices arrival and departure cities inside a country and returns the cheapest city combinations (open jaw) for a date window.

Read `SPEC.md` first. It is the contract for this build; where this file and the spec disagree, the spec wins.

## Commands

- `npm ci` — install
- `npm run dev` — dev server
- `npm test` — vitest, offline, no network
- `npm run lint` — eslint
- `npm run build` && `npm start` — production build and serve on `$PORT`
- `node scripts/build-airports.mjs` — regenerate `data/airports.json` from OurAirports

## Layout

- `src/lib/ranking.ts` — pure ranking and combination logic, no I/O
- `src/lib/providers/` — `types.ts`, `mock.ts`, `ryanair.ts`, `ignav.ts`
- `src/lib/server/` — search orchestration, cache, provider selection (server only)
- `src/app/api/search/route.ts`, `src/app/api/health/route.ts` — API surface
- `data/airports.json` — committed airport subset generated by the script

## Standards

- TypeScript strict, no `any`, no non-null assertions to silence errors.
- Small files named for what they do. Comments explain why, not what.
- Provider credentials are read only under `src/lib/server/`; never import that module from a client component.
- Tests are deterministic and offline. Seed all randomness.
- Conventional commit messages.
